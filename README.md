## Repository contents

| Folder | Description |
|---|---|
| [`ABE_library_screen/`](ABE_library_screen) | Analysis of the adenine base editor (ABE) screen. Python pipeline, library layout files and a notebook for downstream analysis. |
| [`PE_library_screen/`](PE_library_screen) | Analysis of the prime editing (PE) self-targeting library. Snakemake pipeline for read processing and editing analysis. |

Each folder has its own README with setup and run instructions. The two analyses use separate environments.
